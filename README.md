# Credit Card Fraud Detection

## Description
This project detects fraudulent transactions using a hybrid machine learning model combining Random Forest and XGBoost.

## Features
- Handles imbalanced data using SMOTE
- Uses ensemble learning (RF + XGBoost)
- High accuracy and recall

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost
- Matplotlib, Seaborn

## Results
- ROC-AUC: 0.97+
- Recall: 84%
- Accuracy: 99%

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the project:
   python fraud_detection.py
